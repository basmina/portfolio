Case studies

Two problems from the CoreStack cloud governance platform, chosen because the outcome is measurable, not because they were easy.

Centralizing state to kill redundant API calls
NgRx · RxJS · TTL Cache

Problem

Every dashboard navigation independently re-triggered the same backend calls — slow loads, duplicate network traffic, avoidable backend strain.

Approach

Centralized NgRx store as single source of truth, RxJS BehaviorSubjects with map/takeUntil/take(1) operators, enforced subscription cleanup on navigation, and a TTL-based cache for repeat reads in a session.

Outcome

API calls per dashboard load dropped from 10 to 4 — a 60% reduction — with duplicate requests eliminated and lower load on shared backend services.

Decoupling UI so one slow fetch can't block the page
Multi-cloud · Incremental loading

Problem

The data table was coupled to a heavy hierarchy fetch, freezing the entire page while AWS OUs, Azure subscriptions, and GCP folders — three incompatible hierarchy models — loaded.

Approach

Decoupled the table from the hierarchy selector so it renders independently; hierarchy API fires only on user interaction, with the first 50 records eager-loaded and infinite scroll appending the rest.

Outcome

No more blocking on initial load. Users get immediate access to tabular data, and hierarchy exploration stays responsive even for large multi-cloud organizations.

LIVE PRODUCT

DoIt Coach — an AI accountability agent

A conversational coaching app that pushes back on excuses and tracks follow-through, instead of behaving like a passive to-do list.

  • Node.js + Express backend integrated with the Anthropic Claude API; conversation history forwarded per turn so the coach keeps context on user-set goals.
  • All coaching behavior — tone, excuse-challenging logic, win-recognition — defined entirely through system prompt engineering, no fine-tuning or vector storage.
  • MongoDB-backed persistence with Google SSO for auth; deployed on Render with environment-based secrets management.
